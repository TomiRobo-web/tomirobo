# 設計の原則（FOUNDATIONS）

デザインで迷ったときに戻る場所です。上にあるものほど優先します。

## 1. 中身が主役

このサイトの役目は、TomiRobo が何をしているかを伝え、入部・協賛・連絡につなげることです。飾りは、読む人が次の行動（読む・申し込む・連絡する）に進む助けになるときだけ足します。

## 2. 白と黒でつくる

ロゴが白黒なので、サイトも白い地と黒い文字・線で骨格をつくります。まず白黒だけで画面を組み、それで成り立つことを確かめてから藍を置きます。白黒にして区別がつかなくなる画面は、色に頼りすぎです。

## 3. 藍は「押せる・今ここ」の印

藍（`ai`）は富山大学とのつながりを示す色で、意味を1つに絞ります。

- 使う：リンク、主ボタン（1画面に1つ）、メニューの現在地、区切りの英字ラベル、フォーカスの輪。
- 使わない：見出しの文字、本文の強調、広い背景、枠線、装飾の図形。
- 薄い藍（`ai-tint`）の帯は1ページに1か所まで。

## 4. 四角と太い枠

ロゴの四角い枠が TomiRobo らしさです。角は丸めず、強調したい箱だけ 4px の黒い枠（FrameCard）で囲みます。枠は強いので、1画面に2つまで。3つ以上並べたいときは細い線（`line`）の一覧にします。

## 5. 等幅の英字で「機械らしさ」

英字ラベルと日付・数字は等幅フォント（IBM Plex Mono）。図面や基板のシルク印刷の雰囲気を、文字だけで出します。日本語には使いません。

## 6. だれでも読める

- 文字と地の明るさの差は 4.5:1 以上（24px 以上の文字と枠線は 3:1 以上）。`tokens.json` の `usage` に書いた組み合わせなら満たします。
- 色だけで意味を伝えない（現在地は下線も付ける、リンクは下線を付ける）。
- 押せるものは高さ 44px 以上。キーボードで操作でき、フォーカスの輪が見える。
- 画像には `alt`（飾りなら空）。スマホ（幅 375px）で横スクロールが出ない。

## 色

`README.md` の「色のバランス」の表が正です。面積の目安は 白 70 / 黒 20 / 藍 10。

| 地 | 載せてよい文字の色 |
|---|---|
| `paper`・`paper-sub` | `ink`、`ink-sub`、`ink-muted`、`ai`、`ai-deep` |
| `ai-tint` | `ink`、`ai-deep` |
| `ink` | `on-ink`、`ai-light` |
| `ai`・`ai-deep` | `on-ai` |

## 文字

- 1ページに `h1` は1つ。見出しの段を飛ばさない（h1 → h2 → h3）。
- 本文は 16px、行の高さ 30px、1行は全角40字前後（`text-max` 720px）まで。
- 太字は 700。本文中の強調は太字だけ（色・下線・斜体は使わない）。

## 余白と並べ方

- ページの最大幅は `content-max`（1040px）。左右の余白はスマホで 16px。
- 区切り（section）の間は `space-6`（64px）、見出しと中身の間は `space-4`（24px）。
- 幅 768px 以上で横並び、未満は1列。並べる数は最大3列。

## 写真

- ロボット・大会・作業風景の実物の写真を使う。素材サイトの写真や AI で作った画像は使わない。
- 加工（色かぶせ・ぼかし・角丸）はしない。枠を付けるなら細い線（`line`）。
- 人物が写る写真は、本人の了承があるものだけ。
