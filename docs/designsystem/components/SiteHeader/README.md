# SiteHeader

全ページ共通のヘッダー。ロゴと6つのメニュー。

- 下に黒い 2px の線。背景は白。画面に固定しない（スクロールで流れる）。
- メニューは「英字（等幅・大文字）＋小さな日本語」。今いるページに `aria-current="page"`（藍の下線）。
- ロゴは 40px で表示し、横に「TomiRobo」の文字。リンク先はトップ。
- スマホでは折り返して2段になる。開閉するメニュー（ハンバーガー）は作らない。

メニューの項目は `HOME / ABOUT / NEWS / JOIN / SPONSOR / CONTACT`。増減はサイトの `src/components/nav.ts` で行う。

使う側が決めるもの：どのページが現在地か。
