# TomiRobo Design System

富山大学ロボコンプロジェクト **TomiRobo** の公式サイト（https://tomirobo.toyamarobocon.workers.dev/ ）のデザインルールです。人も AI も、サイトの見た目に触る前にここを読みます。

- **正本**：GitHub `TomiRobo-web/tomirobo` の `docs/designsystem/`。ルールを変えるときは必ずそこをプルリクエストで変える。
- **この画面**（Claude の Design System）は、正本を見やすく並べた見本です。食い違ったら正本が正しい。
- 状態：**v0.2**。責任者がデザイン案から「C（藍を全面に）」を基調に選んだ版。

## ひとことで

**藍の扉、白い紙、黒い枠と歯車。**

トップを開いた最初の画面は、富山大学の藍を全面に敷いて白抜きの文字で見せます。そこから先の「読むページ」は白い紙に戻り、ロゴと同じ黒い太枠と歯車で TomiRobo らしさを出します。

## 色の使い分け

| 場所 | 地の色 | 文字・線 | 補足 |
|---|---|---|---|
| HOME の最初の画面（ヒーロー）とそのヘッダー | 濃い藍 `ai-deep` を全面 | 白 `on-ai`、英字ラベルは `ai-light` | 大きな歯車（`ai-mid`）を背景に敷く。ロゴは白い板の上に置く |
| フッター（全ページ） | 濃い藍 `ai-deep` | 白 `on-ai`、リンクは `ai-light` | |
| 読むページ（ABOUT・NEWS・記事・JOIN・SPONSOR・CONTACT、HOME の2画面目以降） | 白 `paper` | 黒 `ink` | 写真・協賛ロゴ・長い文章は必ず白の上 |
| 白い地の上の「押せる・今ここ」 | ─ | 藍 `ai` | リンク、主ボタン、現在地、英字ラベル |
| 強調の帯 | 薄い藍 `ai-tint` | 黒 `ink` | 1ページに1か所まで |

- 藍を全面に敷くのは **HOME のヒーローとフッターだけ**。読むページの背景を藍にしない。
- 色は `tokens.json` にある 14 色だけ。新しい色・グラデーション・影は足さない。
- 写真（ロボット・大会）が手に入ったら、ヒーローの右側（今はロゴ）に入れる。

## AI・作業者への入口（何をするとき、どれを読むか）

| やりたいこと | 読むファイル |
|---|---|
| 初めて触る／全体をつかむ | この `README.md` → `guidelines/FOUNDATIONS.md` |
| 色・文字・余白の値を知りたい | `tokens.json`（値の正。各トークンの `usage` に使いどころ） |
| どの部品を使うか決めたい | `guidelines/COMPONENT_GUIDE.md` → `components/<部品>/README.md` |
| ページ全体を組みたい・直したい | `guidelines/PAGE_PATTERNS.md` |
| 作業の進め方、やってはいけないこと、出す前の確認 | `guidelines/AI_WORKFLOW.md` |
| ロゴを置きたい | `assets/Logos/README.md` |
| 部品の CSS そのもの | `components/bundle.css`（クラス名は `tr-` で始まる） |

**守ること3つ**

1. 色・文字サイズ・余白・角丸は、必ずトークン（CSS 変数 `var(--ai)` など）で書く。`#466d7f` や `24px` を直接書かない。
2. 既存の部品で作れるものは既存の部品で作る。新しい部品が要るときは、先に `components/` に仕様を足してから使う。
3. 迷ったら足さない。読むページは白い余白と黒い線で解決できないか先に考える。

## 文章のきまり

- 読む人は、新入生・保護者・協賛企業・他大学のロボコン関係者。専門用語は言い換えるか、ひとこと説明を添える。
- 文体は「です・ます」。旧サイトの元気さ（「新入部員大募集中！」）は JOIN と NEWS では残してよい。ABOUT・SPONSOR・CONTACT は落ち着いた文にする。
- メニューと区切りの見出しは「英字ラベル＋日本語」の組（例：`NEWS` ／ 活動報告）。英字は大文字、等幅フォント。
- 日付は `2026.11.06`、年度は `2026年度`。日付が分からない記事は「日付不明」。
- 協賛企業名は正式名称に「様」を付ける。
- 絵文字は使わない。「！」は1文に1つまで。

## 見た目の土台

- **形**：四角。カード・画像・帯は角を丸めない。ボタンとタグだけ 2px。
- **枠と歯車**：ロゴと同じく、6px の黒い太枠（`border-frame`）の右上に、枠で切れた黒い歯車を置く（FrameCard）。1画面に2組まで。
- **文字**：見出しは Zen Kaku Gothic New（900 / 700）。本文は BIZ UDPGothic（400 / 700）。英字ラベルと日付は IBM Plex Mono。
- **使用禁止のフォント**（責任者の決定）：Zen Maru Gothic、Dela Gothic One、Noto Sans JP、Shippori Mincho、M PLUS Rounded 1c、Yusei Magic、Klee One、Space Grotesk、JetBrains Mono。
- **余白**：4px を基準にした7段（`space-1`〜`space-7`）。区切りの間は 64px。
- **影・グラデーション・ぼかし・動き**：使わない。ホバーは色の反転だけ。
- **アイコン**：今は使わない（文字と矢印 `→` で足りる）。SNS は文字のリンクにし、各社のロゴは置かない。
